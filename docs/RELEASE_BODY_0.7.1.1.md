The first stable release since 0.6.6.0, on both channels.

- A rebuilt Sort tab: Recommended for a sensible layout in one click, Advanced to set each kind of mod's folder, creator folder and splits.
- Race folders for hair, faces, eyes, skin, tails, ears and horns, and racial scaling packs.
- A reworked Excel workbook: export what Sort suggests, add your own categories, use tokens like {creator}, and get a clear import report.
- Keyword rules: file mods yourself with one-line rules in a small SQL-like language, for example `author = 'Ann' -> Ann's mods`.
- Weapons by job (opt-in): weapon-only mods leave Gear for Weapon/<job>.
- New Heliosphere or Proteus mods that stay protected now get a notice, and the Sort tab shows a status line for them.

Upgrading is safe: your current layout carries over, and nothing moves until you Sort, review and Apply.

Full notes: https://github.com/monstersghost/PenumbraOrganizerPlugin/blob/0.7.1.1/docs/RELEASE_NOTES_0.7.1.1.md
